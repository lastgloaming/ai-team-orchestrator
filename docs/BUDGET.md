# 预算

无已批准的真实预算。建议起点为每月 5 美元，日额度和调用数需作者确认。原型要求提供显式模型、费率、输入与输出上限、每日及每月金额和次数限制、并发及重试上限。低成本默认模型待官方文档复核；需要高性能模型时可以替换配置，所有模型共享同一 SQLite 台账。

金额使用整数纳美元，1 美元为 10 亿纳美元。按最高适用费率向上取整，可保守忽略缓存折扣。按 UTC 统计。每个尝试先在同一事务中检查预算及并发并记录最坏费用，再发请求。必须配置经核对的 provider 输入上限作为保守估计，输出上限随请求发送。已知用量按实际 token 计费；不确定请求保留最大预留。超过设置上限的响应会冻结后续调用，需核对供应商账单。请求超时与指定暂态 HTTP 错误才重试，每次占用独立预算。

`ORCHESTRATOR_STOP=1` 阻止新尝试，已发出的请求可能计费。进程崩溃留下的 active 记录保留费用和并发名额；作者授权的运维人员须确认旧进程已停止并将该记录标记为 uncertain，再恢复名额。生产需要提供受审计的对账入口和远端独立消费上限，工作流环境变量只在新进程启动时刷新。
