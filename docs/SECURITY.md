# 安全

当前事件处理函数是一条内部信任边界。生产适配器应先验证 GitHub 原始 webhook 签名，再验证授权仓库、PR、事件种类和发送主体。签名比较应使用恒定时间，部署时应验证共享主体被排除以及身份映射没有重用。`repository_dispatch` 的任意客户端载荷不能直接作为身份凭据。

可执行任务仅来自固定枚举。评论原文、结果证据、私人正文、受限研究或完整知识库都不进入模型。建议接口只接受固定状态码，对返回字段及枚举做白名单校验。建议不会产生调度消息。拒绝超长正文和重复字段，禁止秘密进入日志或历史。

获批后的运行工作流才可通过 GitHub Actions Secret 注入 `DEEPSEEK_API_KEY`，并结合显式审批开关使用 HTTPS 固定目的地。Mock CI 无 Secrets、只读 GitHub 权限。生产定稿前审查 App 安装范围、持久状态授权、终止开关与审计记录。
